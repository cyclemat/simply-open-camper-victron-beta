So geht'sHow it works

  1. Display per USB-Kabel an den PC anschließen (Datenkabel, kein reines Ladekabel) – beim Waveshare an die Buchse „USB“.
  2. Oben Gerät und Sprache wählen, auf Installieren klicken und im Fenster den Anschluss wählen (meist „USB-SERIAL CH340“ oder „CP210x“) (meist „USB JTAG/serial debug unit“).
  3. Warten, bis „Installation complete“ erscheint, dann das Display neu starten.
  4. Am Handy mit dem WLAN SOC-Victron-… verbinden (Passwort panelsat) – die Einrichtung öffnet sich von selbst.
  5. Die Einrichtung läuft direkt am Bildschirm: WLAN wählen, dann Victron-Geräte, Cerbo GX, Gasflaschen oder Akkus einrichten.
  1. Connect the display to the computer with a USB cable (a data cable, not a charge-only cable).
  2. Choose device and language above, click Install and pick the serial port in the dialog (usually “USB-SERIAL CH340” or “CP210x”).
  3. Wait until “Installation complete” appears, then restart the display.
  4. On your phone, join the WiFi SOC-Victron-… (password panelsat) – the setup page opens by itself.
Achtung: Das Aufspielen hier löscht alle Einstellungen (WLAN, Geräte, Kacheln). Ein schon eingerichtetes Display bitte über seine eigene Weboberfläche aktualisieren (Firmware → Update-Modus, Datei ota/victron-display-cyd.binEditor → System → Firmware aktualisieren, Datei ota/victron-display-ws7.bin).Note: Installing here erases all settings (WiFi, devices, tiles). To update a display that is already set up, use its own web interface (Firmware → Start update mode, file ota/victron-display-cyd-en.bin).
